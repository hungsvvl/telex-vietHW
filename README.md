# Public pages

Served by GitHub Pages at https://hungsvvl.github.io/telex-vietHW/

- `privacy-policy/` - privacy policies for VietKey, Âm lịch Việt Nam, G Navigation (Android, iPhone, Google Play edition), the G Navigation watch app and G Viewer.
- `g-navigation/guide/` - setup guide opened by the G Navigation watch app's QR code.
- `g-viewer/guide/` - setup guide for G Viewer.
- `huawei/` - Huawei watch install guide.

Every page is plain HTML and CSS with no scripts.
