Gnavi 手表应用 · G Navigation 配套应用

Gnavi 隐私政策

Gnavi 是 G Navigation 的手表应用，显示已配对手机上的 G Navigation 应用发来的转向提示、路线地图和到达信息。应用提供基于位置的导航显示，但不读取手表 GPS，也不创建手表端帐户。

简明说明

在您同意后，Huawei Wear Engine 将导航提示、地图图像和路线位置信息从已配对手机传送至手表。位置和提示在内存中处理；地图图像是应用私有临时文件。同意标记、显示与振动设置以及基本设备显示资料保存在本地。

基于位置的显示 — 手机提供导航和地图数据；您同意后，手表应用在手表上显示这些内容。

03

手表应用处理的数据

手机提供与位置有关的数据，包括地图锚点和当前位置坐标、方向、路线图像、道路名称、距离及到达信息。即使手表应用不申请手表 GPS 权限，这些数据仍可能反映您的位置和行程背景。这些个人信息用于提供导航显示功能。

数据用途保留方式
导航、位置及会话数据显示并对齐路线地图、转向提示和到达信息，协调当前会话。在当前会话内存中处理，不保存为行程历史。
地图图像及传入的导航图标显示已配对手机提供的内容。临时保存在应用私有存储空间中，用于显示导航提示。您可以通过清除应用数据（如设备支持）或卸载应用来删除这些数据。
显示和振动设置记住字号、颜色、布局、地图显示、佩戴手腕和振动选项。在本地保存，直至更改、清除应用数据或卸载。
同意标记记住您已接受手表隐私声明。在本地保存，直至清除应用数据或卸载。
设备显示资料和系统语言适配界面并支持相应的显示及连接行为。在本地缓存屏幕尺寸、形状、型号和 API 版本；读取系统语言以选择界面语言。清除应用数据或卸载可删除缓存。

手表应用不读取手表 GPS、健康数据、联系人、通话记录、麦克风、相机、照片或个人文件。应用没有手表端帐户、广告标识符、广告、分析统计或生成式 AI 服务。应用会处理手机发来的位置相关内容。

04

设备权限和同意条件

手表应用的 HAP 未声明 reqPermissions 系统权限。它不请求位置、健康、传感器、联系人、通知、麦克风、相机、照片或文件访问权限。

  • 在您选择同意之前，手表应用只显示隐私提示，不注册 Huawei Wear Engine P2P 接收器。
  • 同意后，手表应用保存本地同意标记，并且只与已配置包名及证书身份的 com.gnavigation.mobile 握手。
  • 选择取消会在注册 P2P 通道前退出。结束导航或关闭手表应用会停止显示导航提示。
05

共享和平台服务

手表应用不会将导航提示发送到开发者运营的服务器，不出售数据，也不会与广告网络或数据经纪商共享数据。它不含分析、广告或跟踪 SDK。

导航提示通过 Huawei Wear Engine 在已配对手机和手表之间传输。Huawei 按其自身条款和政策运营该平台服务；手表应用仅将其作为与已验证的 G Navigation 手机应用通信的 P2P 通道。手表应用本身不向我们的服务器发起 HTTP 请求或网络连接。

手表应用通过 Huawei Wear Engine 向已配对手机上的 G Navigation 发送基本设备显示资料（屏幕尺寸、形状、型号和 API 版本）、应用及协议版本和连接确认消息。手机使用这些信息准备适合手表的导航内容并管理连接。

06

保留、删除和您的选择

您可以在首次声明中选择取消，此时尚未注册 P2P 接收器。结束手机导航或关闭手表应用可停止提示。要删除同意标记、设置、设备缓存和残留临时文件，请在设备支持时清除应用数据，或卸载手表应用。目前没有单独的应用内撤回同意按钮。手机端数据和权限在 G Navigation 手机应用中单独管理。

手表应用不向开发者运营的服务器上传行程。如需访问、更正、删除数据或行使其他隐私权利，请联系 support@gnavigation.men 并说明相关应用和设备。我们可以指导本地删除操作，但无法从服务器提取仅保存在手表上的数据。
