Summary

VietKey does not store per-key logs, does not upload text or audio to a server, and does not use advertising, analytics, or third-party tracking SDKs.

VietKey requests Microphone or Read clipboard permission only after the user accepts the in-app privacy notice and deliberately invokes the corresponding optional feature.

After privacy acceptance, bounded on-device suggestion learning is enabled by default. It can be disabled or cleared at any time and never uploads learned data.

Data Handling

  • Keyboard input is processed locally to provide Telex/VNI/Pinyin typing.
  • VietKey does not store per-key logs or upload keyboard text.
  • VietKey does not include analytics, advertising, or third-party tracking SDKs.
  • The current app package does not declare an internet permission.
  • Offline Voice to Text uses bundled model files on the device. Voice audio is processed locally and is not permanently stored by VietKey.
  • Clipboard data access is optional and remains inactive until the user explicitly enables/uses the feature and grants permission. VietKey stores at most 20 recent items and 20 pinned items locally. Each item is limited to 10,000 characters.
  • After privacy acceptance, on-device suggestion learning is enabled by default. The Vietnamese model stores bounded local counters for up to 800 learned words, 1,500 word pairs, 800 three-word sequences, and 3,000 context patterns. The Chinese model stores up to 300 words and 400 word pairs; Pinyin maintains a local user dictionary.
  • Only valid Vietnamese words and confirmed Chinese/Pinyin candidates are learned. Complete sentences, full input-field contents, links, code, and per-key logs are not stored as learning data.
  • Keyboard settings, custom shortcuts, and user preferences are stored locally on the device.
  • If the user chooses a keyboard background image through the system Photo Picker, VietKey copies one local working copy into its private app storage. It is used only to render the keyboard background, is not uploaded, and can be removed from Theme settings, by resetting app settings, by clearing app data, or by uninstalling VietKey.

Clipboard And Keyboard Input

Keyboard input is processed locally inside the input method. Clipboard features are used only for paste suggestions and optional local clipboard history. Clipboard history can be deleted from VietKey's Privacy Policy page, by clearing app data, or by uninstalling VietKey.

Turning off on-device learning stops new learning but retains existing learned counters. The user can choose Clear learned suggestion data to delete Vietnamese, Chinese, and Pinyin learning data without deleting the custom dictionary.

Consent And Controls

  • VietKey presents an in-app privacy notice before requesting Microphone or Read clipboard permission.
  • Declining does not block the core keyboard. Voice input and clipboard features remain unavailable until the user accepts and deliberately invokes them.
  • Accepting the notice enables bounded on-device suggestion learning by default. The user can disable learning or clear learned data at any time.
  • The user can review this policy, withdraw consent, manage system permissions, delete learned suggestion data, and delete local clipboard history from About > Privacy Policy.
  • Withdrawing consent immediately disables learning and stops VietKey from starting voice input or reading clipboard content. Previously granted HarmonyOS permissions can also be revoked in the system permission settings.
