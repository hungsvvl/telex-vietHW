02

处理的数据

  • 来自手机的大致或精确位置，以及位置服务状态。
  • 行程显示在表盘上期间手表自身的位置：纬度、经度、海拔、精度和定位时间。该运行时不返回速度和方向，精度低于 50 米的定位会被丢弃。
  • 搜索查询、目的地、起点、路线、路线几何信息、行程进度和导航步骤。
  • 手表上绘制的内容：您位置周围的小幅地图图像、转向图标、距离、道路名称和预计到达时间。
  • 手表配对、连接和显示能力状态；网络/Wi-Fi 状态；仅限清单中明确声明、且设置指引需要用到的配套应用和应用商店的安装状态。应用不会扫描全部已安装应用。
  • 当您明确启用通知访问权限和来电提醒时：来电者姓名、来源应用（Zalo 或 Messenger）、响铃/视频通话状态以及来电通知中的操作标签。
  • 用于检测连接或导航会话故障的最少量技术诊断数据。
  • 使用试用或 Premium 时：账户标识符、可用的姓名/邮箱、应用会话、经哈希处理的应用范围 Android 标识符（或随机安装备用标识符）、试用时间和 Premium 权益状态。
  • 包含政策版本、接受时间和所选语言的同意记录——手机和手表各保存一份。

在您接受本政策之前，两个应用都不会初始化地图、位置、Wear Engine、行程缓存或与导航相关的网络请求。手表在首次导航前会显示自己的隐私说明页面，并将您的选择保存在一个本地标记中。

03

处理目的

  • 显示地图、查找地点并根据您当前所在区域排列搜索结果。
  • 计算驾车、摩托车、骑行或步行路线，跟随路线并在需要时重新规划。
  • 维持由您启动的前台导航会话，并显示转向提醒。
  • 通过 Wear Engine 向已配对的华为手表发送导航指引、地图画面和行程状态，并接收手表自身的位置，使腕上地图在两次手机更新之间仍能跟随您移动。
  • 在您启用该可选功能时，转发 Zalo/Messenger 来电提醒以及接听、拒接或挂断操作。
  • 记录两个应用可靠运行所需的同意、设置和状态。
  • 验证账户、限制每个账户和设备的试用、防止欺诈并恢复 Premium。
04

设备权限和访问

手表应用未声明任何系统权限：其 HAP 中没有 reqPermissions 配置块，HarmonyOS Lite Wearable 运行时会直接向正在运行的表盘提供位置、振动和本地存储，不再单独弹窗。下列其余各项均在手机上申请，标记为“可选”的每一项都可以拒绝，且不影响逐向导航功能。

手表上的位置

手表

通过 @system.geolocation 读取，且仅在行程显示于表盘期间读取，使您位置下方的地图在两次手机更新之间持续移动。定位结果经 Wear Engine 发送至已配对的手机，不在手表上留存，也不会发送到其他任何地方。

手表振动

手表

用于转向和导航状态的触感提醒。在该运行时上，system.vibrator 无需声明任何权限即可使用。

手表本地存储

手表

保存您的隐私选择、手机下发的显示设置，以及保留不超过 5 分钟的行程缓存。

大致 / 精确位置

手机

ACCESS_COARSE_LOCATION、ACCESS_FINE_LOCATION——确定位置、优化搜索结果、跟随路线并提供实时导航。

后台位置

手机 · 可选

ACCESS_BACKGROUND_LOCATION——在设置完成后单独提供选择，仅用于应用离开前台或前台服务被系统中断时继续跟踪行程。它不属于核心设置要求。

通知

手机

POST_NOTIFICATIONS、POST_PROMOTED_NOTIFICATIONS——显示正在运行的导航通知和转向提醒；在受支持的 Android 版本上，还会请求系统以 Live Update 形式展示当前行程。

通知访问权限

手机 · 可选

Android 授予系统级通知访问权限。仅在您同意并启用后，G Navigation 筛选 Zalo、Messenger、Telegram 和 Viber 的来电姓名、状态及接听/拒接/结束操作，包括在后台或未导航时。不相关通知被忽略；不会保存或转发聊天消息内容。必要的姓名和状态通过 Android 或配套应用传至所选手表，不上传至 G Navigation 服务器。临时联系人和技术日志详见存储部分。

附近设备（蓝牙）

手机

BLUETOOTH_CONNECT、BLUETOOTH_SCAN（已声明 neverForLocation）、REQUEST_COMPANION_PROFILE_WATCH，以及 Android 11 及更早版本上的旧版 BLUETOOTH/BLUETOOTH_ADMIN——用于查找并保持与已配对手表的连接。应用不会通过蓝牙推断位置，也不申请录音权限。

读取和写入通讯录

手机 · 可选

READ_CONTACTS 和 WRITE_CONTACTS 会单独解释和申请，用通知姓名与代表号码创建临时联系人、检查号码冲突并清理应用创建的条目。查询可能读取匹配联系人以避免覆盖数据；不会上传通讯录或修改已有联系人。临时条目可能出现在通讯录中并由配套应用读取以显示手表来电姓名。拒绝不影响导航和来电提醒，但姓名可能不显示。

由应用自行创建的通话

手机 · 可选

MANAGE_OWN_CALLS 创建本地转接通话；MODIFY_AUDIO_SETTINGS 支持通话期间的蓝牙音频。手表操作交由原通知按钮处理。不会拨打付费蜂窝电话、读取通话记录或录音。通过 REQUEST_COMPANION_PROFILE_WATCH 单独申请的可选 MANAGE_ONGOING_CALLS 仅识别 Android 已处理的 Telegram/Viber 通话所属应用和状态，以避免重复通话；观察服务不读取姓名或号码，也不控制这些通话。Zalo 无需该观察权限。发行版不申请电话状态权限。

前台服务与唤醒锁

手机

FOREGROUND_SERVICE、FOREGROUND_SERVICE_LOCATION、FOREGROUND_SERVICE_CONNECTED_DEVICE 和 WAKE_LOCK 维持您启用的导航或手表来电功能。来电待机有独立通知，未导航时也可运行；关闭功能或撤回同意时停止。RECEIVE_BOOT_COMPLETED 和 REQUEST_COMPANION_START_FOREGROUND_SERVICES_FROM_BACKGROUND 在 Android 允许时恢复已启用功能，不绕过后台启动限制。

重启后恢复运行

手机

RECEIVE_BOOT_COMPLETED——使手表就绪检查在手机重启后重新运行，让已配对的手表无需先打开应用即可连接。该权限不会建立常驻连接。

电池优化豁免

手机 · 可选

REQUEST_IGNORE_BATTERY_OPTIMIZATIONS——打开系统对话框，由您决定长途骑行时是否保持连接。拒绝不会阻止任何功能。

互联网

手机

INTERNET——加载地图、搜索地点、计算路线、登录、验证试用/Premium 状态，并检查 AppGallery 更新。

网络和 Wi-Fi 状态

手机

ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE——在发起网络请求前检查连接状态，并支持 HMS Core/AppGallery 登录或检查更新。G Navigation 不会借此读取 Wi-Fi 密码。

已声明应用的可见性

手机

<queries> 列表中列明了华为运动健康以及设置指引需要检查的应用商店和配套应用。应用不申请查看全部已安装应用。

AppGallery 更新交接

手机 · APPGALLERY 版本

REQUEST_INSTALL_PACKAGES 和 com.huawei.appmarket.service.commondata.permission.GET_COMMON_DATA，由华为 App Service/Update SDK 添加，用于比对版本并打开由 AppGallery 管理的更新界面。G Navigation 不会静默安装，也不会安装任意 APK。

05

数据来源与接收方

离开这一对设备的只有三样东西：您的位置、您在搜索框中输入的内容，以及您要去的目的地。本节说明每一样的来源、传输经过的路径，以及另一端的全部地址。

您的位置来自哪里，用来做什么。在手机上，位置由手机自身的卫星接收模块通过 Android 定位服务读取。在手表上，位置由手表自身的接收模块通过 @system.geolocation 读取，且仅在表盘上正在进行导航时读取，并通过 Wear Engine 发送到已配对的手机——不会保存在手表上，也不会去往别处。两台设备都不通过网络定位服务查询位置，也不会为了取得位置而向任何地方发送请求。位置用于在地图上绘制您的所在处、让地图和箭头保持正确朝向、测量到下一个路口的距离以便手表在恰当时刻显示正确指引，以及记录您之后可在手机上查看的行程。位置只在两种请求中离开手机：算路（需要一个起点）和地点搜索（用一个大致位置把附近的结果排在前面）。位置不会按计划上传，也不会把您走过的轨迹发送到任何地方。

地图取自哪个来源。地图数据为 OpenStreetMap，绘制由手机本身使用 MapLibre GL 完成，样式取自 OpenFreeMap 的 liberty（浅色）和 fiord（深色），二者均由 tiles.openfreemap.org 提供。发送到手表的地图画面是在手机上从同一张图上裁切下来的；手表从不自行获取任何瓦片。手机只向该主机请求覆盖当前屏幕范围的瓦片，该请求不携带账户、不携带目的地、也不携带搜索内容。

数据经由何处发送。下列所有请求均通过 HTTPS 离开手机。算路和地点搜索不会直接发往路线服务或搜索服务：手机把它们发送到 G Navigation 自有服务器，由该服务器校验会话权限后自行向上游发起请求并返回结果。因此上游服务看到的是我们的服务器而不是您的设备，为这些服务付费的凭据也从不存在于应用之中。地图瓦片是例外，由手机直接获取，因为一次瓦片请求除了您正在查看的地图范围之外不说明任何关于您的信息。手表本身不发起任何互联网请求：它显示的一切都通过 Wear Engine 来自手机。

  • OpenFreeMap / MapLibre为手机地图和手表上绘制的画面加载地图样式与瓦片。开源代码：github.com/hyperknot/openfreemap 和 github.com/maplibre/maplibre-native。
  • Photon 或 Nominatim处理搜索查询以及用于排序结果的位置信息。开源代码：github.com/komoot/photon 和 github.com/osm-search/Nominatim。
  • OSRM 服务器根据起点、终点和车辆类型计算路线。开源代码：github.com/Project-OSRM/osrm-backend。
  • 自建 Valhalla 服务器根据起点、终点和出行配置计算摩托车路线。开源代码：github.com/valhalla/valhalla。
  • Huawei Wear Engine在手机与已配对手表之间传输当前会话数据。该传输通道由华为运营；通过它传输的是您的导航指引、地图画面和行程状态。
  • Huawei ID / HMS Core使用授权码验证账户，并在您授权时提供显示名称和邮箱；在取得同意后检查 AppGallery 上的应用更新。
  • G Navigation 权益服务器创建应用会话、按账户和设备限制试用、防止欺诈并恢复 Premium 状态。
  • 备用路线服务仅当您选择“备用”来源计算汽车或摩托车路线时，由手机直接联系：接收起点/终点、重新规划路线时的当前位置，以及用于读取限速的路线周边地图区域，使用应用为每次安装创建的随机访客账户，不与您的 G Navigation 账户关联。

本应用可能联系的全部外部地址，以及联系的用途。除上文所述 G Navigation 自有服务器外，此列表之外应用不会自行联系任何其他地方，手表也不会联系其中任何一个。

  • tiles.openfreemap.org地图样式与矢量瓦片。每次绘制地图时由手机直接联系，包括为手表裁切的画面。
  • g-navigation-get.gg-huawei.workers.dev本应用自己的下载与更新页面，用于询问是否有更新版本。
  • photon.komoot.io、nominatim.openstreetmap.org回应地点查询的 OpenStreetMap 搜索服务。AppGallery 发行版本由我们的服务器调用；关闭网关的开发版本则直接调用。
  • 一台 OSRM 服务器和一台自建 Valhalla 服务器计算路线。只有我们的服务器持有其地址，AppGallery 发行版本从不自行联系。关闭网关的开发版本改用公共的 routing.openstreetmap.de 和 valhalla1.openstreetmap.de。
  • 华为的服务使用华为账号登录、检查 AppGallery 上的应用更新以及配对手表，均由华为自己的 SDK 完成，按华为的隐私政策联系华为的服务器。G Navigation 不向这些请求添加任何自有内容。
  • 备用路线服务的服务器仅在使用“备用”来源时，直接接收来自手机的请求。

G Navigation 只发送您所请求功能确实需要的数据，不出售数据，也不与广告网络或分析服务商共享数据。上面的列表中没有分析地址、没有广告地址、也没有崩溃上报地址，因为应用中并不包含这些组件。

06

保留和删除

  • 路线保存在手机本地，直到被替换或被您删除。
  • 手表保留的行程缓存不超过 5 分钟；显示设置和您的隐私选择会保留至应用被卸载。
  • 手表的定位结果仅用于绘制当前画面，不会写入任何历史记录。
  • G Navigation 不将姓名或通知内容保存为通话历史。姓名可能写入临时联系人供手表查询。无通话约 30 秒后清理应用条目；若 Android 停止应用，会在恢复运行时重试。您编辑或合并过的条目会保留以免丢失数据，可在通讯录中删除。本地最多保存 300 条技术事件，包括时间、来源应用类型、状态、操作结果和错误，不含姓名、号码、通知内容或音频。应用运行或读写日志时清理超过 48 小时的事件；应用停止期间数据可能仍保留在手机上。关闭来电功能、撤回同意或清除应用数据会删除日志，不会自动上传。Android、手表和配套应用可能按各自设置保留已接收数据；G Navigation 无法代其删除这些副本。
  • 同意记录保存政策版本、接受时间和所选语言。
  • 账户会话及与账户关联的试用记录会在完成验证、恢复 Premium 和防止重复发放试用所需的期间内保留，并在账户删除时一并删除。为防止重复试用，应用会保留最长三年的设备标识哈希；该标识不与账户资料关联。
  • G Navigation 服务器不会保留成功登录历史、安装来源报告、搜索文本或路线坐标。地点搜索和路线服务的容量计数仅为全服务汇总，不包含账户或设备标识符。
  • Android 应用已关闭应用数据的系统备份。

在 G Navigation 中打开“设置 > 账户 > 删除账户”，即可删除账户资料及与账户关联的服务器数据。删除账户不会重置试用资格；同一设备上的新账户不会再次获得试用。上述设备标识哈希最长保留三年，仅用于执行这一限制。您还可以查看本政策、撤回同意、删除本地数据或撤销系统权限。若无法访问应用，请发送请求至 support@gnavigation.men，切勿发送密码。卸载手表应用会删除其本地数据。

07

选择与同意

  • 同意按版本记录。当重大变更导致政策版本提高时，两个应用都会请您重新做出选择。
  • 撤回同意会停止导航相关的数据处理，并使应用回到受限的设置界面。
  • 后台位置、通知访问权限、通讯录/来电提醒以及电池优化豁免各自都有独立的说明或选择。
  • 即使拒绝全部可选权限，手机和手表上完整的 OpenStreetMap 逐向导航依然可用。
08

数据安全

发行版本仅允许以 HTTPS 配置地图、搜索、路线、身份验证和政策相关的接口地址。手机与手表之间的连接运行在 Huawei Wear Engine 自有通道中，而非我们自建的开放套接字。G Navigation 将本地保存的数据限定于上述目的，关闭 Android 系统备份，且不将导航指引或来电通知保存为历史记录。

没有任何传输或存储方式是绝对安全的。如果您发现安全或隐私问题，请通过本政策末尾的联系方式与我们联系。

这是托管在 GitHub Pages 某个目录下的静态文档。页面不设置 Cookie、不运行 JavaScript、不使用分析工具、不嵌入广告，也不加载第三方字体或跟踪器。对本页面的访问请求由 GitHub 提供服务，并附带任何网络请求都会有的标准网络信息。涵盖全部手表品牌的完整版政策托管在应用自有的 Cloudflare Worker 上，链接见第 01 节。
